## REBLOOM REQUIREMENTS

A user should be able to:

1. Press a "Rebloom" button.
2. Rebloom an existing bloom.
3. See the rebloom in their own feed.
4. Have the rebloom appear in their followers' feeds.
5. See who originally created the bloom.
6. See who rebloomed the bloom.
7. Clearly distinguish a rebloom from an original bloom.
8. See how many times a bloom has been rebloomed.

## CURRENT PROBLEM

The current Bloom model only knows:

Bloom
|
+-- sender
+-- content
+-- timestamp

It does NOT know:

* who rebloomed it
* which original bloom was rebloomed
* when it was rebloomed
* how many times it was rebloomed
